# Statement

Statement panel displays the logs of all account operations performed by the user for the current day, or for a certain period. In order to open the Working orders panel, select it from the Terminal drop-down list, which is located in the header of the terminal. The panel itself looks as follows:

<figure><img src="../../.gitbook/assets/image (1637).png" alt=""><figcaption></figcaption></figure>

The data is grouped by operation types, for example general account operations (Deposit, Withdrawal, Fee) are listed under “Others”, while trading results are grouped by individual positions.

The following columns are available in the panel:

* Account - name of the account that the account operation is related to;
* Symbol - name of the instrument that the account operation is related to;
* Date - the date of execution of the account operation;
* Operation type - type of the account operation;
* Operation ID - identifier of the account operation in the system;
* Amount - amount of the account operation in account currency;
* Open price - open price of the position. Available only if account operation is related to the position;
* Close price - close price of the position. Available only if account operation is related to the position;
* Quantity - quantity of the position. Available only if account operation is related to the position;
* Currency - account operation currency;
* Position opening date - date of the position opening. Available only if account operation is related to the position;
* Position ID - identifier of the position in the system. Available only if account operation is related to the position;
* Trade ID - identifier of the trade in the system. Available only if account operation is related to the trade;
* Details - any comment left by the broker for an operation.

Note that it is possible to select the time period for data displayed in the table. There is a drop-down list <img src="../../.gitbook/assets/image (1368).png" alt="" data-size="line"> at the top of the panel, which includes 2 options:

* Daily - displays data for the current day;
* Range - activates an additional panel for the period selection.

{% hint style="warning" %}
It is important to note that the Statement panel displays static data, so there is a separate <img src="../../.gitbook/assets/image (1369).png" alt="" data-size="line"> button at the top of the panel for updating/searching the data.
{% endhint %}
