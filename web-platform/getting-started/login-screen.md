# Login screen

Use the main login page to sign in to the VelocityTrader Web platform. A valid login and password are required.

<figure><img src="../../.gitbook/assets/image (1370).png" alt=""><figcaption></figcaption></figure>

### &#xD;**Changing password**&#x20;

Passwords can be changed anytime and using two schemes. The user can reset his password on the login screen before even entering the app or use the Account menu of the app in case he is logged in. The detailed description of each scheme is given below:

#### **Password recovery on the login screen**

In case the user has forgotten his password, he should simply click on the 'Forgot password' button located at the bottom of the login screen. The following wizard screen will be opened, where 3 simple steps should be performed for resetting the password: Enter credentials, Enter verification code and Enter new password.

**Step 1: Enter credentials**

<figure><img src="../../.gitbook/assets/image (1371).png" alt="" width="464"><figcaption></figcaption></figure>

1. Enter your Login in the Login field;
2. Enter your email address in the Email field. Once both fields are filled, the Next button will become active;
3. Click **Next** to proceed. A verification code will be sent to the provided email address.

#### Step 2: Enter verification code

<figure><img src="../../.gitbook/assets/image (1372).png" alt="" width="467"><figcaption></figcaption></figure>

1. Check your inbox for the verification code sent to your email;
2. Enter the code into the **Verification code** field on this screen;
3. Once the correct code is entered, click **Next** to continue to the password reset step.

{% hint style="info" %}
If you go back and return to this step, the verification code field will be cleared.
{% endhint %}

**Step 3: Enter new password**

<figure><img src="../../.gitbook/assets/image (1373).png" alt="" width="466"><figcaption></figcaption></figure>

After successful code validation, you will be prompted to set a new password:

1. Enter your new password in the New password field;
2. Confirm it by entering the same password in the Confirm new password field. The **Recover** button remains disabled until both fields are filled.

If the validation is successful, you will see the message:

<figure><img src="../../.gitbook/assets/image (1374).png" alt="" width="465"><figcaption></figcaption></figure>

#### Password recovery from the app

To open the ‘Change password’ / ’Change trading password’ window, select one of this options in the Account menu.

<figure><img src="../../.gitbook/assets/image (1375).png" alt=""><figcaption></figcaption></figure>

The following steps should be performed to change your password:

1. Enter your current password in the Current password field;
2. Enter your new password in the New password field;
3. Re-enter your new password in the Confirm new password field;
4. Click Save to activate your new password.

Also, you can select the 'Change trading password' option in order to change your personal code which is used before performing trading operations. To change this password the user should perform the same steps listed above.

### **Additional links**

At the bottom of the login screen also may be up to two additional links. These links can be used for various purposes, such as account registration or other important actions, depending on the configuration. A custom text prompt may also be displayed in this area.
