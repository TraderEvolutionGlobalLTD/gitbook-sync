# Hotkeys

A hotkey is a single key or a combination of keys that allows quick access to a specific function. While the same action can be performed using the mouse by navigating through a menu, using the corresponding hotkey is significantly faster. The descriptions provided below outline the functionality within each panel.

### Chart

* Display in full screen mode – allows displaying the chart in full-screen mode.
* Change chart style – allows changing the style of symbol price movements: candle, line, bar, dots, etc.
* Zoom in – allows zooming in on the chart.
* Zoom out – allows zooming out on the chart.
* Auto/Manual scaling – allows switching between Auto and Manual scaling modes.
* Mouse trading – activates trading using the mouse.
* Show/Hide info window – shows or hides the info window on the chart.
* Add indicator – opens a window for adding an indicator to the chart.
* Remove drawings – allows removing all drawings from the chart.
* Show Filled orders – allows displaying filled orders on the chart.
* Set period (Tick, 1 m, 5 m, 15 m, 30 m, 1 H, 4 H, 1 D, 1 W, 1 M, 6 M, 1 Y) – allows specifying the timeframe for the chart.
* Object manager Indicators – opens the settings window for managing indicators on the chart.
* Object manager Drawings – opens the settings window for managing drawings on the chart.
* Object manager Overlays – opens the settings window for managing overlays on the chart.
* Draw Line – allows drawing a line on the chart.
* Draw Vertical line – allows drawing a vertical line on the chart.
* Draw Horizontal line – allows drawing a horizontal line on the chart.
* Draw Arrow – allows placing an arrow on the chart.
* Draw Comments – allows adding comments to the chart.
* Draw Fibonacci retracement – allows drawing Fibonacci retracement on the chart.
* Draw Fibonacci expansion – allows drawing Fibonacci expansion on the chart.
* Draw Fibonacci arc – allows drawing Fibonacci arcs on the chart.
* Draw Fibonacci time goal analysis – allows drawing Fibonacci time goal analysis on the chart.
* Draw Fibonacci fans – allows drawing Fibonacci fans on the chart.
* Draw Fibonacci spiral – allows drawing Fibonacci spiral on the chart.
* Draw Fibonacci time zone – allows drawing Fibonacci time zones on the chart.
* Draw Fibonacci phi channel – allows drawing Fibonacci phi-channel on the chart.
* Draw Triangle – allows drawing a triangle on the chart.
* Draw Polygon – allows drawing a polygon on the chart.
* Draw Rectangle – allows drawing a rectangle on the chart.
* Show/Hide grid – toggles the grid visibility on the chart.
* Show Open positions – allows displaying open positions on the chart.
* Show volume – displays the volume profile on the chart.
* Show Working orders – allows displaying working orders on the chart.
* Bar by bar moving – allows moving through the chart bar by bar.
* Cancel last order on selected instrument – allows canceling the last order on the selected instrument.
* Cancel all active orders on selected instrument – allows canceling all active orders on the selected instrument.
* Cancel Buy order(s) closest to the last price – allows canceling Buy orders closest to the last price.
* Cancel Sell order(s) closest to the last price – allows canceling Sell orders closest to the last price.

### Market depth

* Cancel last order on selected instrument – allows canceling the last order on the selected instrument in the market depth panel.
* Cancel all active orders on selected instrument – allows canceling all active orders on the selected instrument in the market depth panel.
* Cancel Buy order(s) closest to the last price – in case of existence of two orders of different price, the order which is closer to the last price is cancelled. In case of existence of two or more orders of the same price, all orders are cancelled because they are equidistant from the last price.
* Cancel Sell order(s) closest to the last price – in case of existence of two orders of different price, the order which is closer to the last price is cancelled. In case of existence of two or more orders of the same price, all orders are cancelled because they are equidistant from the last price.
* Place Buy order – allows placing Buy order according to the parameters of the order which are set at the panel.
* Place Sell order – allows placing Sell order according to the parameters of the order which are set at the panel.
* Sell Ask – allows placing a Sell order at the Ask price.
* Buy Bid – allows placing a Buy order at the Bid price.

### Order entry

* Open Buy OE – opens the Order Entry panel with the default state set to Buy.
* Open Sell OE – opens the Order Entry panel with the default state set to Sell.
* Place Order – allows placing an order with the parameters set in the Order Entry panel.

### Trading

* Close all positions immediately – allows closing all positions immediately.
* Cancel all orders immediately – allows canceling all active orders immediately.
* Cancel all orders and close all positions immediately – allows canceling all active orders and closing all positions immediately.
* Open Reports – opens the Reports panel to view trading activity reports.

### Working orders

* Modify order – allows modifying an existing working order.
* Cancel order – allows canceling an existing working order.
* Change to Market – allows changing an existing order to a Market order.
