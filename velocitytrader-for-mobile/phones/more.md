# More

This tab is divided into two sections: Tools and More. The **Tools** section provides access to additional features and panels(e.g., Auto-invest panel):

<figure><img src="../../.gitbook/assets/image (188).png" alt="" width="375"><figcaption></figcaption></figure>

In the **More** section, user can access the app settings, view the app info, and more:

* Rate us - allows to rate the app in the Google play or Apple app store and leave the feedback via email;
* Settings – allows accessing the app settings;
* Event log – opens the app event log;
* Help – opens the help menu;
* About – allows viewing the app version info;
* External link – when configured in the Back Office, allows opening an external link content in a dedicated detachable panel named after the link text.
