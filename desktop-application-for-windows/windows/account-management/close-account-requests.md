# Close account requests

Close account request - an option for users to send requests to close their accounts.

It is available in the Account menu when it is allowed for this account:&#x20;

<figure><img src="../../../.gitbook/assets/image (777).png" alt=""><figcaption></figcaption></figure>

By clicking the option, the Confirmation screen with the following buttons appears:

<figure><img src="https://lh7-us.googleusercontent.com/qr5hsd-RemneU9mPGbeZotJreCgg_ev1tB8WRcgp4i5cxLaNnaek4U2sCYvSvpcH0NZoe3udDfW5yQgb7XGKvoh8_JieARCFM1xT3ToHv4m7tP2gKYhKAl4US5IpJopp6nbtiyo_RtIESc5LEAGygnE" alt=""><figcaption></figcaption></figure>

By clicking the “Send request” button the request for closing an account is created and the following screen with ability to cancel a request will appear:

<figure><img src="https://lh7-us.googleusercontent.com/0dEPuJ7va8KpXbdVdSrroHldQXjrjMv-sfbN0eR2Dt3VAcudzlfKFU6vlCXA0rhUEPEFKdmdvmgAAvyypNjpFsdwut1l087PNt3rWmhPDFT2qtFLRK4V9i1V1aOhi91EPL-Z2fTUnqEUmYBSOcmKRl8" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
While the request is being processed, there are no restrictions on the use of the account.
{% endhint %}

The following deal ticket will also be shown, by clicking on which the status of the request will be shown:

<figure><img src="https://lh7-us.googleusercontent.com/bLOlUYXYKuBXHLB9y5arPsXR9d--GGhy3VTFSs3SCvagQRYHsVjnXMw0XILHNWPr-pFKupUvJlMJKvLa-GlEnyuf90C2JTk9C4eMY7ssls-uY_Dd8KD3SN94nuNJkZ1ui6yMJx-vAqRqQXiB5-cPrGg" alt=""><figcaption></figcaption></figure>

There are 4 possible statuses of the closing account requests:

* Submitted - request has been successfully submitted;
* Accepted - the necessary actions will be completed shortly and the account will be closed;
* Rejected - request is rejected;
* Cancelled - request is cancelled.
