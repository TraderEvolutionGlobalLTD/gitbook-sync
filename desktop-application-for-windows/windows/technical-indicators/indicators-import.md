# Indicators import

Users who has access can import their own technical indicators by going to Chart → Add Indicator. The following <img src="../../../.gitbook/assets/image (320).png" alt="" data-size="line"> button at the bottom of the window will be available:

<figure><img src="../../../.gitbook/assets/image (321).png" alt=""><figcaption></figcaption></figure>

By clicking on the button, the following "Import script" window will be opened:

<figure><img src="../../../.gitbook/assets/image (323).png" alt="" width="559"><figcaption></figcaption></figure>

Here you can select files for import. There are two options available: **Add Folder** and **Add Files**.

* Add Folder - allows selecting an entire folder to import all indicators inside it;
* Add Files - allows electing individual files manually.

<figure><img src="../../../.gitbook/assets/image (324).png" alt="" width="559"><figcaption></figcaption></figure>

After that, clicking the <img src="../../../.gitbook/assets/image (325).png" alt="" data-size="line"> will start loading selected indicators. This may take a while. Once completed, the success message will be shown and uploaded indicators will appear in the "Custom" section:

<figure><img src="../../../.gitbook/assets/image (326).png" alt=""><figcaption></figcaption></figure>

Now they can be applied on the Chart:

<figure><img src="../../../.gitbook/assets/timeandsales (1).gif" alt=""><figcaption></figcaption></figure>
