# Getting started

The VelocityTrader Investing application allows a user to grow his capital by investing money in various assets. For novice investors, the advantage of the application is its simplicity, for expert investors it gives plenty of tools to work with. The app is modern, user-friendly and secure. To open the Investing application, use the Segment control at the “More” tab.

![](<../.gitbook/assets/1 - Copy 1.png>)

The interface of the trading application will be changed to the interface of the Investing functionality. If you need to go back to a trading application, use the Segment control again. After logging into the application, a user can start investing.

<figure><img src="../.gitbook/assets/getting started1.png" alt="" width="375"><figcaption></figcaption></figure>

If a user has several Investor accounts, he can choose a certain account by tapping the Account lookup ![](<../.gitbook/assets/image (534).png>) button at the top of the screen and select the preferred account from the list. If it is allowed by the admin, the user can change the names of his accounts:

<figure><img src="../.gitbook/assets/image (77).png" alt="" width="375"><figcaption></figcaption></figure>

To open the account menu, tap the ![](<../.gitbook/assets/image (532).png>) button at the top right corner of the screen. The account menu contains the following options:

<figure><img src="../.gitbook/assets/getting started 3.png" alt=""><figcaption></figcaption></figure>

To withdraw money from an account, select the Withdrawal item. Withdrawing effectively blocks funds from being used in the platform. Select account name and Withdrawal or Remaining amount:

<figure><img src="../.gitbook/assets/image (76).png" alt="" width="375"><figcaption></figcaption></figure>

A user can also easily change the password of the account:

<figure><img src="../.gitbook/assets/getting started 5.png" alt="" width="375"><figcaption></figcaption></figure>

Close account request - an option for users to send requests to close their accounts.

After clicking the ‘Close account’ option, the following confirmation screen will appear:

<figure><img src="../.gitbook/assets/image (79).png" alt="" width="375"><figcaption></figcaption></figure>

By clicking the “Send request” button the request for closing an account is created and the following screen with ability to cancel a request will appear:

<figure><img src="../.gitbook/assets/image (80).png" alt="" width="375"><figcaption></figcaption></figure>

Important note - while the request is being processed, there are no restrictions on the use of the account.

There are 4 possible statuses of the closing account requests:

* Submitted - request has been successfully submitted;
* Accepted - the necessary actions will be completed shortly and the account will be closed;
* Rejected - request is rejected;
* Cancelled - request is cancelled.

By clicking on such a notification, the corresponding screen with additional information will appear.
