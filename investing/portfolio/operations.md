# Operations

This tab shows the information about the completed account operations:

<figure><img src="../../.gitbook/assets/image (1217).png" alt="" width="375"><figcaption></figcaption></figure>

Each card contains the following data:&#x20;

* Operation type - type of the completed operation. The following operation types are available: Deposit, Withdrawal, Transfer, Blocking, Unblocking, Trading, Swap, Custodial, Funding;&#x20;
* Date - time and date when the operation was completed;&#x20;
* Value - the price shown in the account’s currency.

To see operation details, swipe the card left and tap <img src="../../.gitbook/assets/image (491).png" alt="" data-size="line"> button:

<figure><img src="../../.gitbook/assets/Opdetails.jpg" alt="" width="375"><figcaption></figcaption></figure>

Note that the user can select a data range for which the operations will be shown. Tap the button to choose the range:

<figure><img src="../../.gitbook/assets/image (1218).png" alt="" width="375"><figcaption></figcaption></figure>

Also a user can group the operations, to do this tap on the grouping <img src="../../.gitbook/assets/image (492).png" alt="" data-size="line"> button and select the needed option:<br>

<figure><img src="../../.gitbook/assets/image (493).png" alt="" width="375"><figcaption></figcaption></figure>
